# No Boundaries Construction LLC — example website

A one-page example website for No Boundaries Construction LLC (NBC), an excavation, grading and demolition contractor serving residential and small commercial projects in Western Washington.

**Live site:** https://johnlyon-groundfloorindustries.github.io/NBC/

## What is on the page

- **Services:** excavation and site preparation, grading and land clearing, demolition and tear-outs.
- **On the job:** project photos, with a link to more on the company's Facebook page.
- **Service areas:** Grays Harbor, Kitsap, King, Pierce, Lewis and Pacific counties.
- **Contact:** phone and email links. There is no contact form, and the page collects and stores nothing.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The page. |
| `style.css` | Layout, colors and type. |
| `assets/equipment.jpg`, `assets/sitework.jpg` | Photos used on the page. |

## Viewing and updating

No installation or build step. Use the live site, or open `index.html` in a browser. Fonts load from Google Fonts, so the page needs an internet connection to display as designed.

The site is published with GitHub Pages from the root of the `main` branch. A push to `main` updates it within a minute or two.
